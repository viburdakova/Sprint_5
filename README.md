# Sprint 5

## UI-тестирование - Этот проект содержит автоматические тесты для проверки функциональности сайта, включая регистрацию, вход, выход, создание объявлений и проверку элементов интерфейса.

## Описание проекта

Данный проект предназначен для автоматизированного тестирования функциональности веб-приложения, включая следующие аспекты:

- Регистрацию пользователей
- Авторизацию пользователей
- Выход из аккаунта
- Создание объявлений пользователями

Тестовые сценарии реализованы таким образом, чтобы обеспечить максимальную независимость друг от друга и повторяемость результата.

Или индивидуально:
